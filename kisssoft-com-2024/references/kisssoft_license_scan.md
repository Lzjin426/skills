## 说明

- `CheckLicense` 是判断模块是否可用的最可靠方式。
- 某些模块可能返回 True，但仍需要对应扩展文件（`*.Z*`、`*.M*` 等）才能实际运行。
- 本扫描只验证 license 权限，未验证每个模块是否能完整加载并计算。
- 用户许可证工具（截图）显示更多模块已勾选，但 COM API 的 `CheckLicense` 只返回上述 True 的模块。可能原因：
  - 截图中的勾选表示“安装”而非“授权”
  - 许可证工具中的设置需要应用/保存后才能生效
  - 部分模块需要额外的 license feature（如 S20x 系列权利）

## 测试代码

```python
import win32com.client
ks = win32com.client.Dispatch("KISSsoftCOM2024.KISSsoft")
mods = ['Z011','Z012','Z013','Z014','Z015','Z016','Z017',
        'Z050','Z051','Z052','Z060','Z070','Z080','Z090',
        'W010','W020','S020','M010','M020','M030','M040','M050','M060',
        'F010','F020','F030','F040','F050','A010','A020','K010','K011','K012','K013','K019']
for m in mods:
    print(m, ks.CheckLicense(m))
```
