# 踩坑与收获

**⚠️ AI 上下文压缩导致输出质量劣化**

5.30 做系数对齐测试时发现 deepseek 在上下文被多次压缩后表现很差，改用 codex 一次就跑出了可信结果。根因不是模型能力差异，而是长对话中的上下文压缩会累积信息损失。涉及需要精密计算或严格逻辑验证的任务时，优先选择新会话或切换模型，而不是在同一个长对话里硬撑。

**💡 Craft Agent 的 mermaid 和 markdown 渲染体验出色**

5.26 尝试 Craft Agent 后，发现其自带的 mermaid 图表和 markdown 渲染质量很高，主要面向文字细节场景。虽然它的记忆机制只有用户偏好是永久记忆（5.27 调研结论），但在特定文本处理场景下可以作为补充工具纳入工作流。

**⚠️ 从零搭建知识库耗时远超预期**

5.27 尝试让一个知识点一个知识点搭建知识框架，发现过于耗费时间且效果不佳。根因是 AI 的知识深度、幻觉率和不同 AI 的能力差异会让这种"渐进式知识建构"变得低质低效。对于需要系统性掌握的新领域，直接看书建立框架比让 AI 逐点拼凑更可靠。

# 内观与发现

把本周和 `5.18～5.24-26` 的"下周聚焦"逐条对照，论文双线的推进超出了预期，但另一条线的变化更值得被看见。上周列的"准备 6 月 8 日入职恒润的交接与准备"本周完全没有动作，取而代之的是 5.28 体检后写下的"要认真考虑下延期去实习，推迟 1-2 周"——这不是拖延，是身体数据带来的决策偏移。体检发现脂肪肝、尿液蛋白质和隐血，这些信号和过去几周反复出现的疲劳记录连在了一起。`5.04～5.10-26` 开始提醒"增加运动和休息时间"，`5.11～5.17-26` 记录"五周连续身体信号"，`5.18～5.24-26` 再次提醒"给身体状态设一个具体动作"。本周终于用体检这个动作回应了持续数周的信号，但结果不是"虚惊一场"，而是确实需要干预。这意味着"延期实习"不是随口一说，而是需要纳入下周决策的真实选项。

Skillsbase 的推进节奏在本周完成了一个自然的"脉冲式衰减"。`5.18～5.24-26` 修复了近十个 issue 并恢复了 Git 系统，5.25 又密集修复了 9 个 issue，但 5.26 之后这条线几乎从日报中消失。这不是被挤掉了——本周并没有出现比 skillsbase 优先级更高的新主线——而是这条线在一轮密集的技术债清理后，剩余事项（Git 系统优化、Skill 更新历史视图）没有立即产出感，所以注意力自然滑向了更有反馈的论文投稿和中期答辩。这和 `5.11～5.17-26` 观察到的模式一致："当一个任务需要等待外部反馈、没有即时产出感时，你会自然地滑向那些有即时反馈的任务"。Skillsbase 没有停滞，只是从"密集迭代期"进入了"等待收口期"。

还有一个容易被忽略的点：本周的"调研型投入"密度不低——Claude Code 记忆机制、Craft Agent 记忆机制、agent-task-sizing、Git Worktree、PDF 本地化规范——这些都发生在 5.27 一天之内。它们没有产出具体的代码或论文段落，但本质是你在为下一阶段的"AI 协作工作流"做认知升级。`4月-26` 里把"把高频工作工具化"列为最值钱的投入方向之一，本周这些调研是在为下一批 skill 或工具改进储备认知素材。只是请记得，调研的终点是应用，如果下周还是只看不练，这些认知会快速贬值。
