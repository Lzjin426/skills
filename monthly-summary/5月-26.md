## Skillsbase经历从高峰到衰减的完整脉冲

**✅ 阶段成果**：Skillsbase 完成 Mac 平台迁移，V1.3.9 发布，Git 系统恢复，累计修复近 20 个 issue。

# 踩坑与风险

**⚠️ AI 上下文压缩导致输出质量劣化** `进行中`

5.30 系数对齐测试中发现 deepseek 在上下文被多次压缩后表现很差，改用 codex 一次跑出可信结果。根因是长对话中的上下文压缩会累积信息损失。涉及精密计算或严格逻辑验证的任务时，优先选择新会话或切换模型，不要在同一个长对话里硬撑。

**⚠️ 身体疲劳信号持续累积并获体检验证** `进行中`

从 `4月-26` 起连续数周出现疲劳记录，"增加运动和休息时间"反复出现在周报聚焦中但始终没有具体动作。本月体检确认脂肪肝和尿液异常。这不是"忙完这阵就好"的问题，需要饮食、运动、复查的系统性干预。

**⚠️ 软著实名认证因照片方向问题卡住** `进行中`

5.9 发现手持身份证照片不能镜像，认证失败。淘宝代申请花费 170 元但仍需等自己账号实名通过后才能继续。

**⚠️ 并行任务超过阈值后效率反而下降** `已解决`

5.7 记录下这个观察：不同人能够并行处理的任务有上限，一段时间内做过多并行任务，比单独做某一个效率更低。切换任务和分配时间本身有隐性成本。这个问题不是新知识，但本月的状态反复验证了它。

**💡 标准 md 化是 AI coding 的可复用基建**

IEC61400-4 和 iso7902 的本地 md 化完全复用了 ISO6336 的成功路径。这套方法从 `4月-26` 验证到本月第二次使用，已确认为可沉淀的资料工程范式。

**💡 飞书导出 docx + codex + docx skill 处理格式重排**

风电调研报告最后一步验证了这条链路，AI 对 word 的处理精度已到"指哪打哪"，下次涉及格式重排、表格统一类工作可以直接复用。

# 内观与发现

把 5 月和 `4月-26` 的"下月聚焦"逐条对照，兑现情况呈现明显的两极分化。4 月列的 P1"等待英文论文反馈并准备接续修订"——本月英文论文仍在等审稿人，没有任何推进，从 4 月等到 5 月底，这条线已经从"准备修订"变成了"持续失联"。"等待中文论文 V1 反馈并推进修订"——超预期兑现，不是等到反馈再改，而是初审直接通过。"完成 MeshPro 软著材料终版"——本月完全没有提及，这条线从桌面消失了。P2 项的兑现率更低：skillsbase 多端同步与 JSON 冲突问题在 5 月的高密度迭代中似乎被自然消化，但没有被明确标记为完成；归档 con-skill/for_ruanzhu 等历史项目没有动作；确定去向——这条倒是完成了，但不是通过"给截止时间"的主动方式，而是通过组会和恒润电话被动推进的。

Skillsbase 的脉冲式节奏是本月最值得分析的模式。4 月它从 V1.2 推到 V1.3.4 并启动 UI 重构，5 月从 V1.3.9 到 Mac 迁移修复近十个 issue——两次高峰之间的低谷期（`5.11～5.17-26`）恰好对应新电脑到货前的等待窗口。`5.11～5.17-26` 已经提醒过"消失不等于解决"，下旬的强势回归验证了这一点。这揭示了一个规律：开发热情与硬件条件强相关。当旧电脑成为瓶颈时，Skillsbase 会自然降级；当新设备到位后，它会以报复性密度反弹。这不是坏事，但意味着不能指望这条线在硬件受限时保持匀速推进。

身体状态是本月另一个从"背景噪音"升级为"前台议题"的变量。`4月-26` 和之前多期周报都在提醒"增加运动""恢复休息"，但始终只停留在聚焦列表里。直到 5.28 体检数据出来，这条线才真正获得决策权重——甚至影响到了已经敲定的入职时间。这个转折本身说明了一件事：对抽象的健康提醒免疫，但对具体的体检指标敏感。如果 6 月真的延期实习，那不是因为"觉得累了"，而是因为脂肪肝和尿液异常给了无法忽视的外部验证。但请记得，体检只是诊断，不是治疗。延期换来的时间如果不配套具体的干预动作，那就只是把问题往后推了。

最后说一条跨主线的连接。本月在论文、Skillsbase、工具调研三条线之间反复迁移了一套方法论："标准 md 化→结构化上下文→AI coding"。从 ISO6336 到 IEC61400-4 和 iso7902，从飞书多维表格替代 GitHub Issue 到 Craft Agent 记忆机制调研——这些动作的底层逻辑是一致的：把高频、重复、需要结构化信息的任务先做好资料基建，再让 AI 在清晰的边界内工作。`4月-26` 把这叫作"把高频工作工具化"，5 月把它从"代码领域"扩展到了"论文领域"和"项目管理领域"。这是本月真正值钱的积累，不是某篇论文的某个版本号，而是一套正在跨领域迁移的工作范式。
